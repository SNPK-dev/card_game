# Chronicle Forge — быстрый старт для Windows

## Требования

- Windows 10/11 x64.
- Сервер включает .NET runtime; отдельно устанавливать его не требуется.
- Не менее 4 ГБ свободного места.

## Автоматический запуск

1. Распакуйте релизный архив в папку с правом записи.
2. Запустите `PLAY.bat` из корня распакованного релиза.
3. Подождите запуска локального сервера и игрового клиента.
4. Создайте аккаунт. Пароль должен содержать не менее 12 символов.
5. Откройте **Forge Cards**, выберите локальный режим или OpenAI Connector и создайте 15 разных карт.
6. В **Deck Workshop** сохраните колоду из 30 карт, выберите её и запустите **Play vs Bot**.

Локальная генерация выполняется моделями Ollama и Stable Diffusion. Перед выбором этого режима выполните инструкцию `LOCAL-GENERATION.md` из архива или [инструкцию в репозитории](local-generation.md): первый запуск требует скачивания моделей и дополнительного места на диске. Для режима OpenAI перед запуском создайте рядом с `PLAY.bat` файл `.env` со строкой `OPENAI_API_KEY=...`. Не передавайте этот файл вместе с релизной папкой.

`PLAY.bat` устанавливает production-окружение, запускает авторитетный API на `http://127.0.0.1:5000` с постоянным хранилищем `data/`, ждёт его готовности и запускает `client/windows/CardGame.exe`.

## Ручной запуск локального сервера

Откройте PowerShell в корне распакованного релиза:

```powershell
$env:ASPNETCORE_ENVIRONMENT = "Production"
./server/Game.Api.exe --urls http://127.0.0.1:5000 --Storage:RootPath=./data
```

Не закрывайте терминал сервера. Во втором терминале запустите клиент:

```powershell
./client/windows/CardGame.exe
```

Для запуска API непосредственно из репозитория используйте:

```powershell
dotnet run --project src/Game.Api --configuration Release --no-launch-profile --urls http://127.0.0.1:5000 --Storage:RootPath=artifacts/local-player-data
```

Проверка доступности:

```powershell
Invoke-RestMethod http://127.0.0.1:5000/health
```

Ожидаемый ответ содержит `status: ok`. Для пользовательского запуска всегда задавайте `Storage:RootPath`, иначе данные будут храниться только в памяти и пропадут после перезапуска.

## Данные и диагностика

- Аккаунты, коллекции, колоды, настройки, матчи и данные replay хранятся в `data/`.
- Логи находятся в `logs/` и не должны содержать пароли или исходные токены.
- Сервер по умолчанию слушает только локальный адрес `127.0.0.1:5000`.
- Целостность файлов можно проверить по `SHA256SUMS.txt`.
- Если клиент сообщает о недоступности сервера, закройте оба процесса и снова запустите `PLAY.bat`.

## Ручная предрелизная проверка

Перед публикацией выполните полный сценарий из [инструкции ручного предрелизного прогона](manual-release-test.ru.md). В распакованном релизе она находится рядом с `PLAY.bat` под именем `MANUAL-RELEASE-TEST-RU.md`. Передайте тестировщику архив `artifacts/releases/Chronicle-Forge-Windows-latest.zip` и попросите вернуть заполненный GO/NO-GO-протокол из конца инструкции. Сценарий включает три темы, русский и английский языки, локальную и OpenAI-генерацию по 15 карт, коллекцию, CRUD колод, полный матч, replay, переподключение и сохранение данных.
